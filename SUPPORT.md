# Getting help

This repository has no issue tracker: support for the CatWandConnect Home Assistant integration happens in the main project.

- **Bug:** [open an issue in CatWandConnect](https://github.com/vistorx/CatWandConnect/issues/new/choose) and pick *Home Assistant integration (HACS)* as the area. Include your Home Assistant version, the integration version and the robot's firmware version.
- **Question:** the [CatWandConnect Discord](https://discord.gg/Rbqge3v9dk).
- **Security vulnerability:** [private report](https://github.com/vistorx/CatWandConnect/security/advisories/new), never a public issue.

Full details: [Getting help](https://vistorx.github.io/CatWandConnect/support/).
